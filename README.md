# CLI Portfolio

A modern, interactive portfolio website styled as a Linux Ubuntu terminal. Built with Next.js 16, React 19, and Tailwind CSS v4.

## Features

### Terminal Commands

- `help` - Display all available commands
- `ls` / `dir` - List files and folders with interactive elements
- `cd <directory>` - Navigate directories with case-insensitive support
- `pwd` - Print current working directory
- `clear` - Clear terminal screen
- `about` - Show personal introduction
- `skills` - List technical skills with proficiency bars
- `experience` - Display work experience timeline
- `projects` - Browse project portfolio
- `achievements` - View certificates and awards
- `social` - Display social media links
- `contact` - Show contact information
- `cv` - Download CV/Resume
